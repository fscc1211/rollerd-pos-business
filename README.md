# RollLerd POS & Business V3

Prototype ระบบต้นทุน สต็อก การซื้อขาย และตรวจสอบเงินทุน

## เปิดใช้งาน
- แตกไฟล์ ZIP แล้วเปิด `index.html` ในเบราว์เซอร์
- ข้อมูลบันทึกใน Local Storage ของเบราว์เซอร์/อุปกรณ์นั้น
- ใช้เมนูด้านบนเพื่อแก้ราคาวัตถุดิบ สูตร ซื้อของ รับสต็อก บันทึกยอดขาย และตรวจนับเงินจริง

## ข้อจำกัดสำคัญ
- V3 นี้เป็นต้นแบบใช้งานในเครื่องเดียว ยังไม่มี Supabase, ระบบ Login, สิทธิ์เจ้าของ/พนักงาน, การซิงก์หลายอุปกรณ์ หรือ backup cloud
- ก่อนใช้เงินจริง ให้ตรวจสอบ/แก้ไขปริมาณสูตรและหน่วยซื้อที่ทำเครื่องหมายสมมติฐานหรือรอยืนยัน
- ซอสข้าวซอยยังไม่ได้ใส่ปริมาณต่อกล่อง เพราะข้อมูลเดิมมีตัวเลขไม่ตรงกัน
- การรับของเข้าสต็อกและจ่ายเงินแยกการติ๊กในเวิร์กโฟลว์ซื้อของ; รายการรับเข้าคิดตามจำนวนที่รับจริง
- ต้นทุนที่แสดงเป็นต้นทุนวัตถุดิบตามสูตร ไม่รวมค่าแรง ค่าเช่า ค่าสาธารณูปโภคและของเสีย จนกว่าจะบันทึกเพิ่ม
- อย่าลบข้อมูลเบราว์เซอร์ก่อน export/backup (ฟังก์ชัน export ยังไม่ได้ทำในรุ่นนี้)

## การพัฒนาขั้นต่อไป
เชื่อม Supabase database + authentication + role-based access + transaction-safe stock ledger + export/backup + audit trail ก่อนเปิดใช้หลายคนจริง
