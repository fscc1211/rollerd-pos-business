# RollLerd POS & Business v0.2
Prototype includes Dashboard, Tasks, Plans, Products, Ingredients & Prices, Recipes & Yield, Purchase Plan, Sales, Stock, Accounts, Finance, Staff & Wages, Reports, and Settings.

Seed data includes the 4-day trial plan (20 boxes/day, 80 boxes, 320 pieces), 3 menu products, ingredient prices, and initial recipe/yield information. Unconfirmed values are explicitly marked as assumptions.

IMPORTANT: this is a localStorage prototype, not yet shared across devices. Role switching is visual only, not real authentication or authorization. Formula-to-product costing, automatic stock deduction, full purchase calculations, Supabase Auth and database Row Level Security still need implementation and testing before live use.
